

**Project Scope & Vision**

- NSF-funded CSSI project focused on geophysical data, simulation, and integration using AI, with landslides as the primary use case
- Broader ambition: expand methods to other geohazards (floods, droughts, volcanoes) across depth sensitivities
- Petascale data challenge — starting at petabytes, requiring lean, efficient, cloud-optimized code

**Data Infrastructure**

- Two major archives: ~200 PB satellite (SAR) data at ASF; ~4 PB ground-based sensor data at EarthScope
- ASF also hosts ECMWF global weather modeling cubes
- Prototype "data hub" (led by Nicoletta and Scott) already built: aggregates sensor + raster data into analysis-ready cubes, staged on S3 or GitHub Actions
- Goal: avoid unnecessary data duplication; use direct archive access where possible

**Technical Pillars**

- Data fusion (CNN, image classification, time series + satellite)
- Data assimilation with physical models — gateway to digital twins
- AI surrogate models for acceleration
- Agentic workflows: co-designed with scientists, evaluated against real research workflows
- Full reproducibility is a prerequisite for agents to function reliably

**Year 1 Priorities**

- Define specific use cases; polish data aggregator
- Establish AI-readiness standards for extreme/rare event data
- Build reproducible workflows that double as agent evaluation sets
- Communicate the project clearly to non-experts (raised by Michael)
