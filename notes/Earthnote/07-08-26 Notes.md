 
 A real LFE is:
  - steep negative spectral slope (sp_slope) — energy falls off fast with frequency
  - low-frequency, concentrated in 2–8 Hz (low sp_centroid/sp_rolloff85, high bf_2_4/bf_4_8)
  - HF-depleted (low hf_ratio, low bf_16up) — the opposite of an earthquake
  - strongly S-polarized (high hv_ratio, planarity, rectilinearity) — LFE energy lives on the horizontals
  - emergent, not impulsive (low env_kurt/env_crest, longer rise_time) — the classic LFE gradual onset vs an EQ's sharp spike

The class means make it concrete: LFE hv_ratio 3.69 (highest of all classes) vs EQ 2.70 vs noise 1.43; LFE centroid 7.3 Hz vs EQ 10.2 Hz

Stage 0 — Inputs (one-time)

  - PNSN tremor catalog catalogs/pnsn_tremor_cascadia_full.csv — the space-time windows where tremor was detected (starts ~2010). This
  is the only place tremor windows enter.
  - Continuous waveforms for the station (downloaded per-station, e.g. data/waveforms/PB.B011/).

  Stage 1 — Candidate detection 
 
  - Script: scripts/discover_nllb_pnsn_driven.py --station <STA> 
  - What: only inside PNSN tremor windows near the station, find envelope-peak arrivals.
  - Out: sta_pnsn_candidates_100km.parquet — (time, lat, lon, snr, station). (B011: 1.67 M.)
  - Real LFEs + noise + EQs, all mixed.
 
  Stage 1b — Picker score (optional; done at B011 only) [REAL-LFE]
 
  - Script: lfe_features/score_candidates.py + model models/tremor_picker_b011.joblib
  - What: tag each candidate with P(LFE) from the fingerprint; keep ≥0.5.
  - Out: b011_cand_p50.parquet (82,582 of 415k).
 
  Stage 2 — Cluster into families [REAL-LFE — this is where "families" are made]

  - Script: scripts/discover_gpu.py --station <STA>
  - What: all-pairs max-shifted cross-correlation on 2-s Z windows; cc ≥ 0.8, complete-linkage; keep clusters with ≥3 members across 
  ≥3 years. Each surviving cluster = one LFE family with a seed template. (Incoherent noise doesn't repeat → dropped here.)
  - Out: <sta>_pnsn_families_100km.{npz, summary.csv, members.parquet}.
- Stage 3 — Select + shape pre-screen [REAL-LFE]

  - Scripts: scripts/select_coverage_families.py (coverage-balanced + top-10% SNR add-back + family-CWI spiky-shape screen) →
  scripts/plot_selection_map.py
  - What: pick the families worth densifying; drop noise-shaped ones. → show maps, pause for your confirm.
  - Out: <sta>_coverage_selection.summary.csv.

  Stage 4 — Densify (matched-filter across the FULL record) [PNSN windows no longer used]
 
  - Script: scripts/densify_gnw_gpu.py (via densify_launcher.py), --despike-mad 8
  - What: take each seed template and matched-filter it across the entire continuous record (2007–2017), tremor or not. ~3–9 seeds →
  thousands of detections/family. This is where the dv/v data is actually built.
  - Out: mf_<sta>_all.csv (or per-year mf_<sta>_YYYY.csv).
 
  Stage 5 — Daily coherent stacks
 
  - Script: scripts/build_long_window_resp.py, --despike-mad 8
  - What: per family, 30-calendar-day causal rolling stack + SVD-Wiener denoise → one clean daily waveform per family.
  - Out: long_window_daily_<sta>.npz.
 
  Stage 6 — Coda dv/v (stretch)

  - Script: scripts/dvv_roll30cal.py --origin-anchor
  - What: stretch/CWI on the 2–4 s coda lapse window vs reference, anchored at pinned-S (t=1.0). → dv/v(t) per family per day.
  - Out: daily_dvv_<sta>_2to4[_calS].csv.
 
  Stage 7 — Trust battery (certification) [REAL-LFE]
 
  - Script: scripts/family_trust_tier1.py
  - What: per family — stack-vs-random coda σ, day/night cc, reversed-template null → GOLD / TRUSTED / UNDET / FAIL.
  - Out: family_trust_tier1_<sta>.csv → merged results/family_verdicts/ALL_families_labeled.csv.

 Stage 8 — Multi-window inversion
 
  - Script: fault_tomography/inversion/invert_multiwin.py
  - What: combine per-family dv/v across lapse windows (1–3, 2–4, 3–5 s) × stations → δβ/β field on the plate interface.
  - Out: fault_tomography/inversion/fault_4d_multiwin_*.npz.
