We are trying to create a Agentic system

You have a main orchestrator agent that receives a user request and makes a plan. Then it can call specialized agents. For example,a knowledge agent that handles version documents and decision history, and a coding agent for repos and tests, and a data or science agent to run analyses and plots. Then all of that shares a provenance and memory layer. So you can trace any answer back to sources and versions and an evaluator loop that checks whether evidence is sufficient or contradictory, andonly then returns a grounded answer. Wrap that with a cautious self-improvement loop like fail, analyze, propose fixes, test on a benchmark, adopt only if it helps. So that way it's more like an engineering copilot with memory and accountability than just a chat frontend.
