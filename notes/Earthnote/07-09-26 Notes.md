## How it parallelizes (the 3-lane conveyor)

Each station touches all 3 lanes, so different stations overlap:

```
NET:  download(1) stn N+2 ────────────────────▶ …
GPU:  cluster(4)+densify(6) stn N ─▶ stn N+1 ─▶ …
CPU:  detect(2)+score(3) stn N+1 ; AppB(5) ; stack(7)+trust(8)+dvv(9) stn N-1
```

- **GPU** does the two heavy discovery steps (cluster + densify).
- **CPU** does everything else — detection, scoring, App B, stacking, trust, dv/v — for _other_ stations while the GPU is busy.
- **NET** stays ahead downloading.

**No trace deletion** anywhere (your last instruction) — traces are held through stages 7–8 which need them.
