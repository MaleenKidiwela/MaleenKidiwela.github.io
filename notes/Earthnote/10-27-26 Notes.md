Travel-time tomography is only one of six data types, each seeing part of the subsurface the others can't:

|Data|What it measures|Best for|
|---|---|---|
|Earthquake travel times|direct P and S times through the crust and slab|static 3-D structure; long-term change, especially in Washington|
|LFE direct-wave timing, per episode|changes in S and P times from the slip zone to stations|the shallow and mid forearc (0–24 km) per episode, and where the sources sit|
|LFE coda stretching|velocity change along scattered paths|deep velocity change (25–47 km and the slow layer), unaffected by source position|
|Autocorrelation echoes|two-way time to reflectors below each station, every 30 days|the column under each station, continuously 2003–2026|
|Receiver functions|sharpness of boundaries, from distant earthquakes|contrast changes in the slow layer (Gosselin-type), per station|
|Static reference (Merrill + updates)|the 3-D velocity model itself|the ray paths and sensitivity maps everything else uses|

They all go into one inversion. Each enters with its own sensitivity map and its own calibrated errors, and the data decide how much to trust each one. Then the cross-checks:

- **Leave one data type out:** the others must predict it.
- **Synthetic changes:** planted changes must be recovered correctly.
- **Scrambled controls:** must show nothing.

The result is one 4-D model, where every cell's change over time is backed by whichever data types can actually see it, and says which ones those are.
