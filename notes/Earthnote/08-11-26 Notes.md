**Why the per-pair mean of dv/v can be solved inside the space–time inversion**

Write the field we want as m(x, t) — dv/v as a function of position and time — and let pair p have sensitivity kernel K_p(x), normalised so that Σ_x K_p(x) = 1. A single measurement is

  d_p(t) = K_pᵀ m(·, t) + c_p + ε_p(t)

The constant c_p appears because dv/v is measured against a reference stack over some window R_p:

  d_p(t) = K_pᵀ m(·, t) − (1/|R_p|) Σ_{s∈R_p} K_pᵀ m(·, s)

So c_p = −K_pᵀ m̄_{R_p}. If every pair used the same reference window, c_p would be fully determined by m and there would be nothing to estimate. It becomes a free parameter precisely when pairs have different usable spans, or when there are per-pair processing offsets — response changes, a switch between stretching and MWCS, changing station availability inside the stack.

**The augmented system.** Stack m over all cells and epochs into a vector of length MT, and the offsets into c of length P. Then

  d = G m + S c + ε

where G places K_p into the block for epoch t, and S is the pair-indicator matrix, S[(p,t), q] = δ_pq. Since c enters additively and linearly, this is the original system with P extra columns. Nothing about the inversion changes structurally.

**The null space, and why your reference choice is the fix.** Take any time-independent field f(x) and set m(·, t) = f for all t, c_p = −K_pᵀ f. Then G m + S c = 0 exactly. A static velocity anomaly is indistinguishable from a set of per-pair offsets, so the augmented system has a null space of dimension M. Imposing

  (1/|R|) Σ_{t∈R} m(x, t) = 0  for all x

supplies exactly M constraints and removes it. That condition *is* the statement "the reference is the last year of the stack" — the reference window is the gauge that makes c estimable, rather than an extra assumption layered on top.

**Solving for c costs almost nothing.** The normal equations are

  [[GᵀWG + Λ  GᵀWS]] [m]   [GᵀWd]
  [ SᵀWG      SᵀWS ] [c] = [SᵀWd]

SᵀWS is diagonal and P×P — entry p is just the summed weight of pair p — so eliminating c is a rank-P update:

  ĉ = (SᵀWS)⁻¹ Sᵀ W (d − G m̂)

Substituting back gives

  (Gᵀ W̃ G + Λ) m̂ = Gᵀ W̃ d,  W̃ = W − W S (SᵀWS)⁻¹ SᵀW

W̃ is the projector that removes the weighted mean of each pair's time series. **Solving for the offsets is algebraically identical to demeaning every pair before inverting** — the same "within" transformation as a fixed-effects panel regression. Which route you code is a matter of convenience; keeping c explicit has the advantage that you get its posterior covariance, and pairs with few epochs get correspondingly loose offsets instead of being demeaned by a noisy sample mean.

**Three consequences.**

The time-average of m is not recoverable, by construction. Only temporal variations are constrained, which is all dv/v means anyway.

You consume P degrees of freedom. With daily samples under a 31-day average carrying roughly 160 independent epochs per pair, that matters for any pair with a short span.

Regularisation on m must not fight the gauge. If Λ includes a temporal-smoothness or damping term that penalises m toward zero, it partially determines the mean and quietly reintroduces the trade-off with c. Damp toward the reference-window mean instead, or apply the constraint as a hard projection.
