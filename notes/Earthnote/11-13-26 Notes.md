I taught Marine's machine learning class today talking about how the training, validation and testing datasets are made for different projects. 
They learned about adding gaps so that data is not leaked, how to keep training and test populations separate, what's the importance of starting with a simple model, persistence test, and how sometimes no matter what hyper parameters you use, the model result doesnt get better. But this can be better mitigated by changing the question rather than changing the model. 
For example: GNNS station positions in the past can be used in a random forest to predict how much the position changes from the current in the future, instead of designing the forest to predict the absolute position. Such a change in the question sometimes perform better.
