## LFE picker — the 23 hand-crafted features

The picker uses **23 hand-crafted features** per window (defined in `lfe_features/feature_defs.py`), in three groups. LFEs are low-frequency, S-polarized, and emergent — so each feature points a known direction for a real LFE. Continues [[06-15-26 Notes]].

## Spectral shape (13) — the core

| feature | what it is | LFE signature |
|---|---|---|
| `sp_slope` | log-log spectral slope (2–40 Hz) | steep negative ← top discriminator |
| `sp_centroid` | spectral centroid (Hz) | low (~3–4 Hz) |
| `sp_spread` | spectral bandwidth | narrow |
| `sp_peakfreq` | peak frequency | low |
| `sp_rolloff85` | 85%-energy rolloff freq | low |
| `sp_flatness` | spectral flatness | — |
| `sp_entropy` | spectral entropy | — |
| `bf_1_2`, `bf_2_4`, `bf_4_8` | energy fraction in 1–2 / 2–4 / 4–8 Hz | high (energy in 2–8 Hz) |
| `bf_8_16`, `bf_16up` | fraction in 8–16 / 16–Nyquist Hz | low |
| `hf_ratio` | E(>8 Hz) / E(2–8 Hz) | low (HF-depleted) |

## Envelope / onset (7) — emergent vs impulsive

`env_crest` (peak/RMS), `env_kurt`, `env_skew`, `rise_time` (10→90%), `duration` (>half-max), `zcr` (zero-crossing rate), `snr` (signal vs pre-event noise).

→ LFEs are emergent (low crest/kurtosis, slow rise), unlike impulsive earthquakes/blasts.

## Polarization (3) — requires 3-component

`hv_ratio` (horizontal/vertical energy), `rectilinearity`, `planarity`.

→ LFEs are S-dominant → high H/V. `hv_ratio` is the single strongest discriminator in the picker.

## The heavy lifters

Across the validations, the features that actually carry the separation: `hv_ratio` (polarization), `sp_slope`, the 2–8 Hz band fractions, `hf_ratio`, `sp_centroid`, and the envelope shape (`env_skew` / `env_crest` / `env_kurt`). Two important properties we verified:

- **SNR-independent** — dropping all amplitude features (`snr`, `env_crest`) left the AUC unchanged, so it's waveform character, not loudness.
- **Polarization is in here** — so the vertical-dominance flag (`hv_ratio`) is already part of the categorizer, not a separate filter.

(That's the hand-crafted set. Separately, R6 showed an unsupervised spectrogram autoencoder rediscovers the same LFE structure — latent AUC 0.965 — confirming these aren't arbitrary.)
