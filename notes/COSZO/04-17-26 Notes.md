## Variability CSV — column reference

One row per (station × date), appended to
`output/temporal_anomaly/metrics/<STATION>_variability.csv`
by `bin/temporal_anomaly_investigator.py` in collect or single mode.

### Identity

| Column | Description |
|---|---|
| `date` | Date of the data day (YYYY-MM-DD) |
| `station` | OOI reference designator (e.g. RS01SLBS-MJ01A-06-PRESTA101) |
| `deployment` | 1-indexed deployment number auto-detected from param files |
| `has_data` | True if OOI returned data; False if fetch failed or fewer than 2 points |

### Day window

| Column | Description |
|---|---|
| `data_start` | UTC timestamp of first sample in the day |
| `data_end` | UTC timestamp of last sample in the day |
| `n_points` | Number of samples returned for the day |

### Fitted clock (from the plan)

| Column | Description |
|---|---|
| `sp_nominal` | Nominal sample period from param file (e.g. 1.000000 s for dep2) |
| `dt_FG` | First-guess interval $\Delta t_{FG} = \mathrm{median}(\Delta t'_j)$ — plain median of adjacent timestamp differences |
| `dt_true` | Fitted true sample interval $\Delta t_{\text{true}}$ — OLS slope of $t'_j$ vs reconstructed index $i_j$ |
| `t_i0_offset_s` | Fitted start-time offset $t_{i=0}$ from OLS, expressed in seconds relative to the first sample. Small values (≈ ms) indicate the first sample lands on the fitted ideal grid |

### Gaps (derived from $\Delta i_j > 1$)

| Column | Description |
|---|---|
| `n_gaps` | Number of adjacent pairs with $\Delta i_j = \mathrm{round}(\Delta t'_j / \Delta t_{FG}) > 1$ |
| `gap_total_missing` | Sum of $(\Delta i_j - 1)$ over all gaps — estimated total missing samples |

### Jitter in milliseconds

Residuals $e_j = t'_j - [t_{i=0} + i_j \, \Delta t_{\text{true}}]$, converted to ms.

| Column | Description |
|---|---|
| `jitter_mean_ms` | $\mu_{\mathrm{ms}} = \mathrm{mean}(e_{j,\mathrm{ms}})$ — should be ≈ 0 by construction of the OLS fit |
| `jitter_std_ms` | $\sigma_{\mathrm{ms}} = \mathrm{std}(e_{j,\mathrm{ms}})$ — primary spread metric |
| `jitter_maxabs_ms` | $\max \lvert e_{j,\mathrm{ms}} \rvert$ — worst single-sample deviation |

### Jitter as fraction of sample interval

Normalised by the fitted interval: $f_j = e_j / \Delta t_{\text{true}}$.

| Column | Description |
|---|---|
| `frac_mean` | $\mu_f$ — mean fractional jitter |
| `frac_std` | $\sigma_f$ — std of fractional jitter |
| `frac_maxabs` | $\max \lvert f_j \rvert$ — worst fractional deviation (multiply by 100 for %) |

### Consistency diagnostic

| Column | Description |
|---|---|
| `max_abs_epsilon` | $\max \lvert \Delta i'_j - \mathrm{round}(\Delta i'_j) \rvert$ — how far the floating step counts stray from integers. Near 0 ⇒ first-guess interval is appropriate; approaching 0.5 ⇒ ambiguous rounding |

### Output flag

| Column | Description |
|---|---|
| `figure_generated` | True if the 4-panel per-day figure was written to `output/temporal_anomaly/figures/per_day/<station>_<date>/` |
