## Metrics collected in `diagnose_timing.py` collect mode

One row per (station × date) appended to `output/diagnostics/metrics/<STATION>_metrics.csv`.

### Identity

| Column | Description |
|--------|-------------|
| `date` | Date of the data day (YYYY-MM-DD) |
| `station` | OOI reference designator (e.g. RS01SLBS-MJ01A-06-PRESTA101) |
| `deployment` | Deployment number auto-detected from param files (1, 2, …) |
| `has_data` | True if OOI returned any data for this day; False if API returned nothing |

### Day boundaries

| Column | Description |
|--------|-------------|
| `data_start` | UTC timestamp of the first sample in the day |
| `data_end` | UTC timestamp of the last sample in the day |
| `missing_start` | True if first sample arrives more than 1 × sp_nominal after midnight — data absent at start of day |
| `missing_end` | True if last sample arrives more than 1 × sp_nominal before the next midnight — data absent at end of day |

### Sample counts

| Column | Description |
|--------|-------------|
| `n_points` | Number of samples actually returned for the day |
| `expected_npts` | Expected number of samples based on the actual data window: `round((data_end − data_start) / sp_calc) + 1`. Excludes missing data at day boundaries — those are captured by `missing_start`/`missing_end`. |
| `is_full` | True if `n_points` ≈ `expected_npts` (within a small tolerance). False means samples are missing within the data window. |

### Gap detection

| Column | Description |
|--------|-------------|
| `n_gaps` | Number of gaps detected using adaptive threshold (multiplier × sp_calc) |
| `n_segments` | Number of contiguous data segments (= n_gaps + 1) |
| `gap_total_duration_s` | Total time missing across all gaps (seconds) |
| `gap_max_missing` | Largest single gap in estimated missing samples |
| `gap_total_missing` | Total estimated missing samples across all gaps |

### Sample rate

| Column | Description |
|--------|-------------|
| `sp_calc` | Robust median of inter-sample intervals (lower 90th percentile Δt). What the sensor *typically* does that day. |
| `sp_fit` | Least-squares slope through all timestamps. Average rate across the full day — sensitive to start/end position. |
| `sp_nominal` | Nominal sample period from the param file. What the sensor *should* do (e.g. 1.000000 s for dep2). |
| `sp_deviation` | `abs(sp_calc - sp_nominal)` — absolute deviation of typical rate from design spec |
| `sp_fit_deviation` | `sp_fit - sp_nominal` (signed) — day-average drift from nominal |
| `sp_calc_minus_fit` | `sp_calc - sp_fit` (signed) — skewness signature: positive means median interval > mean, i.e. distribution has a left tail (more short intervals than long) |
| `sp_alert` | True if `sp_deviation` exceeds the alert threshold (`max(0.05 s, 5% × sp_nominal)`) |

### Jitter (per-segment, in ms)

Jitter measures how far each sample is from ideal timing *within* its segment, insensitive to linear drift.  
Formula: `|Δti − round(Δti / sp_seg) × sp_seg| × 1000`  
Using `sp_seg` (per-segment robust median) means systematic clock drift doesn't contaminate this metric.

| Column | Description |
|--------|-------------|
| `jitter_mean_ms` | Mean jitter across all samples in the day (ms) |
| `jitter_median_ms` | Median jitter (ms) |
| `jitter_std_ms` | Standard deviation of jitter (ms) |
| `jitter_p95_ms` | 95th percentile of jitter (ms) — the primary summary metric |
| `jitter_max_ms` | Maximum single-sample jitter (ms) |

### Timing residuals (per-segment, in ms)

Residuals measure how far each sample's timestamp deviates from the per-segment best-fit line — captures random irregularity after removing linear drift.

| Column | Description |
|--------|-------------|
| `res_std_ms` | Standard deviation of residuals (ms) |
| `res_p95_ms` | 95th percentile of absolute residuals (ms) |
| `skewness` | Skewness of the residual distribution. Near 0 = symmetric random noise; large negative = systematic drift pattern; large positive = occasional late arrivals. |

### Output

| Column | Description |
|--------|-------------|
| `figure_generated` | True if a per-day figure was generated (only happens on anomaly: n_gaps > 0, is_full = False, or sp_alert = True) |
