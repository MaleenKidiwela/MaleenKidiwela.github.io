
### New Earthscope dropoff system

**1. Pull the repo**

  cd /path/to/sea-water-velocity && git pull

  
  **2. Install the EarthScope CLI into the env** (one-time)

  conda env update -n ooi_env -f VEL3D-data-collection/bin/environment.yml

  # or the quick version:

  conda run -n ooi_env pip install earthscope-cli

  
  **3. Log in to EarthScope** (one-time per machine; needs your EarthScope account)

  conda run -n ooi_env es login        # opens a browser device-code flow

  conda run -n ooi_env es user get-profile   # confirms auth works

  If you don't have contributor permission for network OO yet, email data-help@earthscope.org now —

  uploads will stall at AUTHORIZING until that's granted, but everything below can still be done. 
  

  **4. Fix the staged MiniSEED codes** — your backfill ran before the renames, so the staged files still

  say SHBP/OSBP, MOE/MON/MOZ, CZOFF loc 20:

  cd VEL3D-data-collection

  conda run -n ooi_env python bin/fix_staged_mseed_codes.py --dry-run   # preview

  conda run -n ooi_env python bin/fix_staged_mseed_codes.py             # rewrite headers + 

  filenames


  **5. Upload** (the script finds es via conda automatically, so plain invocation works)

  bin/dropoff_earthscope.sh mseed --dry-run     # sanity-check the file list

  bin/dropoff_earthscope.sh mseed --archive     # upload; sent files move to output/mseed2dmc_sent/

  bin/dropoff_earthscope.sh xml                 # the five StationXMLs

  
  **6. Verify server-side processing**

  bin/dropoff_earthscope.sh status              # summary: RECEIVED → … → ACCEPTED

  bin/dropoff_earthscope.sh list vel3d/mseed/   # per-object statuses

  

  Two tips: for the very first real upload, consider testing with a single file before the full backlog — temporarily move all but one file's year dir aside, or just accept that a FAILED batch costs nothing (fix and re-upload the same keys, no re-staging needed). And if anything shows FAILED in status, bin/dropoff_earthscope.sh history <key> shows the failure message for that object.
