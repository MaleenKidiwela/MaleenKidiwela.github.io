
### new changes to coszo website 

Instrument pages 
  - COSZO Instruments page: added full instrument specifics from cascadiaoffshore.org for every sensor — makes/models
  - (Nanometrics Atlantis T360-COBST2, HTI-90-U hydrophone, Paroscientific Series 8000, Nortek Vector, etc.), specs, and
  - calibration details for the GSSM and SCPR; added a Science Junction Box section and a references block; removed the
  
  Short-Period Seismometer section.
  - Absolute pressure: the data page now lists both generations — existing gauges (Slope Base, Southern Hydrate Ridge, Axial Base) and the new COSZO stations (Outer Shelf, Oregon Offshore, Mid Slope) as pending entries, with a per-site pressure-range table on the instruments page.

  Live cruise tracker for RR2608 (6a9c529, 58a4bfc, 87266e0) — built, pushed, but switched off
  - Data feed: a script pulls the Roger Revelle's full AIS track from the SIO/UNOLS scheduling site; a GitHub Action refreshes it every 30 minutes during the cruise window (Aug 20 – Sep 6) and commits as the github-actions bot. Outside thewindow it does nothing.
  - Interactive hero banner (behind CRUISE_TRACKER_ENABLED in build_pages.py): when on, the homepage headline shows for 1.5 s, then fades into a two-panel live view
  - left, a map framed on the six deployment sites (black triangles linking to site pages) plus Newport, with the cruise track, orange end-of-day dots that link to that day's Blog from Sea diary, and a blinking ship-hull marker rotated to the vessel's heading; 
  - right, the existing live video stream. The page re-fetches the track every 30 minutes while open, and falls back to the static banner if data or the map library is unavailable.
