## Wall-clock cross-check — added to temporal_anomaly_investigator

Followed up on yesterday's SLBS 2025-01-26 anomaly (raw classifier flagged
1 gap / 1 missing sample, but wall-clock arithmetic said the day was
whole). Implemented the cross-check in `compute_variability()`:

```
n_expected_wall = round((data_end - data_start) / sp_nominal) + 1
if n_points >= n_expected_wall:
    n_gaps = 0
    gap_total_missing = 0
    gap_positions = []        # → no red markers in Panel D
```

Raw classifier output preserved as `n_gaps_raw` / `gap_total_missing_raw`
so nothing is lost — just demoted from "gap" to "jitter artifact" when
the wall clock says no sample is physically missing.

### CSV schema changes

New columns: `n_expected_wall`, `n_gaps_raw`, `gap_total_missing_raw`.
`n_gaps` and `gap_total_missing` now carry the corrected (post-cross-check)
values. Wiped the three `*_variability.csv` files and re-collected the

### Re-run result — 2025-01-22 → 2025-01-26, all 3 stations

15/15 succeeded (AXBS 01-25 came back this time — OOI Cassandra healthy).

| Date | Station | n | n_exp_wall | n_gaps (raw → corr) |
|---|---|---|---|---|
| 01-23 | SUM1 | 86400 | 86400 | **1 → 0** |
| 01-26 | SLBS | 86400 | 86400 | **1 → 0** |

Two spurious gaps suppressed. Both days had `n_points == n_expected_wall`,
confirming no physical dropout — the raw `1` was a ±0.5 rounding
artifact around Δi = 1.5 (a single jittered interval paired with a
matching Δi = 0 elsewhere in the day, net zero missing samples).

Real dropout days (01-24, 01-25) retained their full gap counts on all
three stations, as expected — on those days `n_points < n_expected_wall`
so the cross-check correctly leaves the classifier output alone.
