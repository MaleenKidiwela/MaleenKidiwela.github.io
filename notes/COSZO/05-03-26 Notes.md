
## Vaultnotes

Vaultnotes is a lightweight AI-powered notes assistant that turns a personal Markdown vault into a searchable knowledge interface. It uses a static hybrid RAG pipeline, where notes are preprocessed into chunks, embedded with Gemini embeddings, and stored as a browser-accessible index. At query time, Vaultnotes combines BM25 keyword search, lexical matching, and semantic vector search, then fuses the results to retrieve the most relevant note chunks before sending them to a language model for response generation. The system is designed to run efficiently on static hosting, with a Cloudflare Worker handling secure model calls and API access, while the frontend performs local retrieval over prebuilt index files. To reduce cost and rebuild time, Vaultnotes also uses a content-hash embedding cache, so unchanged notes do not need to be re-embedded.
