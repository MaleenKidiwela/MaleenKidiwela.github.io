## How to build & ship (read first)

- **Source of truth is `build_pages.py`** — the `*.html` files are generated. Edit the Python (body constants, `FOOTER`, `build_header`, `render_people`, `PEOPLE_GROUPS`), **not** the HTML directly.
- **Styling** → `styles.css` (static, hand-edited). **People data** → `data/people.csv`.
- **Build:** `python3 build_pages.py` (regenerates all pages + `search-index.json`).
- **Verify:** serve the repo dir on a fresh port (`python3 -m http.server 8788` from the repo root — a stale server on 8765 serves a different site) and screenshot with Playwright, or check the generated HTML.
