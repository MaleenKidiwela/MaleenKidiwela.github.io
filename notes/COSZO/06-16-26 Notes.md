  # direct `conda run -n ooi_env python …` calls need the source above.

  **1. (Optional) regenerate param files + roster**
  conda run -n ooi_env python bin/make_vel3d_params.py

  **2. Metadata → StationXML  (output/xml/OO_HYSB1.xml)**
  # single station, direct:

  conda run -n ooi_env python bin/create_metadata.py RS01SLBS_MJ01A_12_VEL3DB101

  # …or all 5 stations via the wrapper (also fetches OOI deployment metadata):

  bin/run_ooi_requests.sh all all seedlink

  Note: the wrapper's metadata mode is all-stations-only (all all); use create_metadata.py for just HYSB1.

  **3. Waveform → MiniSEED**
  No --stream needed — VEL3D-B auto-detects its single stream.

  # (a) seedlink / near-real-time → output/mseed/ ; auto-uses latest deployment

  conda run -n ooi_env python bin/OOI_data_request_and_convert_mseed.py \

      RS01SLBS-MJ01A-12-VEL3DB101 vel3d seedlink

  # (b) miniseed2dmc / historical backfill → output/mseed2dmc/YYYY/

  #     FIRST set deployment = 3 in param/run_vel3d.txt (currently 12), then:

  conda run -n ooi_env python bin/OOI_data_request_and_convert_mseed.py \

      RS01SLBS-MJ01A-12-VEL3DB101 vel3d miniseed2dmc

  Each invocation processes one time_interval (86400 s = 1 day) from the run/endtime_…txt cursor (both

  cursors already exist for HYSB1); loop/re-run to walk a backfill range.

  **4. Timing QC — temporal-anomaly investigator**

  # collect a date range  (→ output/temporal_anomaly/metrics/RS01SLBS_vel3d_b_sample_variability.csv)

  conda run -n ooi_env python bin/temporal_anomaly_investigator.py --mode collect \

      --station RS01SLBS-MJ01A-12-VEL3DB101 --stream vel3d_b_sample \
      --start 2025-09-01 --end 2025-09-07 --only-gaps --save-nc

  # cross-day summary plots

  conda run -n ooi_env python bin/temporal_anomaly_investigator.py --mode plot \
