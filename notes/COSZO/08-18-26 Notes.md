##### Here are some instructions on how to set up the RAID Drive

The RAID drive is currently formatted to ExFat and should be compatible with mac/ windows/ linux

Step 1: Download and install the driver from the Pegasus32 download center
https://www.promise.com/us/Support/DownloadCenter/Pegasus/Pegasus32/R6#Drivers

Step 2: Download and Install PROMISE Utility Pro
https://www.promise.com/us/Support/DownloadCenter/Pegasus/Pegasus32/R6#Utilities

Step 3: Plug the RAID drive to an outlet and plug it to a computer using a USB-C Lightning port

When connected, all the lights will blink blue. The RAID drive will not turn on if it is not plugged to the computer through a compatible port

If it is a Laptop, the lightning cable will function as a charging cable for the laptop. 

Step 4: Open the PROMISE Utility Pro, when connected, it will show up as a unit that when clicked will provide all the information about the performance of the drive. A folder will appear in the finder toolbar as an external drive.
