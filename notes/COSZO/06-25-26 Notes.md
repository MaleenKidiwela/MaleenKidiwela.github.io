**Data Quality & QA/QC (CORTAD)**

- Wendi M. warned that systems set up before commissioning tend to stick and are hard to change later
- CORTAD applies filters (gross range, spikes, flat lines, nearest neighbors) and flags data as FAIL if outside sensor range
- OOI uses a "Human in the Loop" flag and annotates NetCDF files so future users see flagged data
- A Discourse forum and GUI are used to communicate data issues to users
- EarthScope has no native user notification system for data corrections
